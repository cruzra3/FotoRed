# PROJECT.md

## Nombre
FotoRed

## Objetivo
Crear una aplicación web con funcionalidades similares a Instagram.

## Tecnologías
- Python
- Streamlit
- SQLite inicialmente

## Funcionalidades deseadas
1. Registro e inicio de sesión
2. Perfiles de usuario
3. Publicar fotografías
4. Feed de publicaciones
5. Likes
6. Comentarios
7. Seguir usuarios
8. Buscar usuarios

## Primera versión
Crear un prototipo con:
- Página principal
- Feed de fotografías de ejemplo
- Perfil de usuario de ejemplo

No requiere autenticación ni base de datos real en esta primera versión.

## Consideraciones
Construir progresivamente.
No asumir que Streamlit puede replicar todas las características de Instagram.
Usar identidad visual original.
